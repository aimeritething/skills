# skills

Personal agent skills for Claude Code and other AI agents.

## Install

```bash
npx skills add aimeritething/skills
```

## Skills

| Skill | Description |
| --- | --- |
| [show-me](skills/show-me) | Explain the current topic visually — one focused HTML page opened in the browser, inline sketches for small points. |
| [terminal-diagrams](skills/terminal-diagrams) | Colored blueprint schematics drawn inline in the chat reply — bar charts, tables, flows, nested-box diagrams. |
